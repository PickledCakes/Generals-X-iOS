# Public iOS collection release preparation

The source fork preserves upstream history and attribution while adding the collection launcher and shared compatibility changes. Users supply whole installations and select their bundled profiles. Build configuration, proprietary archives, generated icons and signed artifacts are excluded.

Validation: nine portable content tests; real Zero Hour advisory checks and staging; successful Xcode Release launcher build and unsigned app packaging using the existing validated engine frameworks. Selected-profile packaging excludes unused engine frameworks and game folders. No device installation was performed for this publication.

The new cold dependency-and-engine build path is documented but has not yet been exercised from an unrelated clean Mac. Checksums describe reference assets rather than a guarantee of content authenticity.
